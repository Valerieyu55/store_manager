# 今天，我開了一間手搖飲店

一套融合數學（連比例／比例式）、創業模擬與 UI 設計的高中數學任務型課程（PBL），
以「YOUR TEA COMPANY」互動網頁遊戲的形式呈現。

## 課程架構

學生扮演新創手搖飲品牌的「產品企劃總監」，依序解鎖五個部門任務：

| Mission | 部門 | 數學核心 |
|---|---|---|
| 01 | 研發部 | 連比例 — 找出飲料配方 |
| 02 | 調飲實驗室 | 比例、比例式 — 量產換算 |
| 03 | 財務部 | 百分率、比例 — 成本與定價 |
| 04 | 行銷部 | 比例、版面尺寸 — 廣告設計 |
| 05 | 新品發表會 | 綜合應用 — 自訂配方、完整企劃書 |

## 功能

- 逐關解鎖的辦公桌 Dashboard，含進度追蹤
- LINE 訊息風格的情境對話與連比例互動謎題
- 每一步驟的填空計算引擎，附「已知資訊」提示卡避免忘記前面算過的數字
- Mission 03 的定價決策卡片（即時顯示成本率、毛利）
- Mission 04 的廣告版面即時預覽
- Mission 05 讓學生自訂配方、生成專屬的新品企劃書
- 進度自動存檔（跨裝置共用儲存），中途可隨時返回辦公桌
- 教師模式（密碼登入）可查看全班學生的作答情況與分析

## 使用方式

用瀏覽器直接開啟 `index.html` 即可執行，不需要安裝任何套件。

若透過 GitHub Pages 發布，開啟 repo 的 Settings → Pages，
將來源設為此分支的根目錄，即可取得公開網址。

## 營業版：一杯剛剛好（`cup/`）

`cup/index.html` 是延伸的遊戲化版本，保留上面五個 Mission 的劇情與核心關卡，
每個部門再加上「營業衝刺」：客人排隊點單、題目隨機生成、星星解鎖下一個部門。
另有動畫、音樂與音效、設定面板與教師後台。

GitHub Pages 網址：`https://valerieyu55.github.io/store_manager/cup/`

原本的 YOUR TEA COMPANY（根目錄 `index.html`）不受影響。

> 注意：`cup/` 的全班進度回傳使用 Claude 平台的資料庫，只有在 claude.ai 上開啟才會運作；
> 從 GitHub Pages 開啟時，進度只會存在學生自己的裝置上。
